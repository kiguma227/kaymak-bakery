# Kaymak — лендинг кондитерской

Одностраничный сайт кондитерской на заказ в Аликанте: авторские торты, капкейки, десертные столы.
Чистые HTML, CSS и JS, без фреймворков и сборки.

**Сайт:** https://kiguma227.github.io/kaymak-bakery/

## Структура

```
index.html        разметка, мета-теги, Open Graph, JSON-LD
css/styles.css    токены, типографика, секции, адаптив
js/main.js        хедер и меню, появление при прокрутке, фильтр, просмотр фото, форма, карта
assets/           favicon и шрифты Playfair Display и Inter (SIL OFL 1.1)
```

## Локальный запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```
python -m http.server 5173
```

## Перед запуском в работу

Сейчас это демо-версия.

- Имя мастера, телефон, Instagram, адрес, цены и отзывы вымышлены — замените на настоящие.
- Форма никуда не отправляет данные: подключите Formspree, Telegram-бота или свой сервер в функции `sendOrder` в `js/main.js`.
- Уберите `<meta name="robots" content="noindex">` в `index.html` и пометки «Демо» в футере и в подтверждении заявки.
- Фото подключены прямыми ссылками с Unsplash и Pexels — замените на фото своих работ.
